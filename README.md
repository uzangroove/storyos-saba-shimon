# StoryOS – סבא שמעון

מרכז הפעלה דיגיטלי בעברית לכל פעילויות סבא שמעון: שעת סיפור בהמחשה, כשהציור קם לתחייה, תיאטרון בובות, עולם קטן – קסם גדול, ושיר נולד בגן.

## מצב גרסה

העבודה הנוכחית מתבצעת על `release/storyos-v22-production` כענף ההכנה לפרודקשן. הענף נוצר מעל `release/storyos-v21-management`, כך ש־v20, v21 והיסטוריית `main` נשמרים ללא שינוי.

## יעד v22

- לאחד את כל הרכיבים שכבר נבדקו לגרסת Production אחת.
- לשמור על חמש הפעילויות במסך הראשי ובמצב ההפעלה החי.
- לשמור על תכני StoryOS, מצגות/PDF, בקרות מאוחדות ותכני `שיר נולד בגן`.
- לשמר את מודול `כשהציור קם לתחייה` ואת תשתיות הגן/הגלריה שנבדקו, בלי לחזור למבנה Preview נפרד.
- לפרסם מתוך `public` ב־Netlify לאחר בדיקת Release סופית.

## תוכן פעיל

- שעת סיפור בהמחשה — 16 ספרים פעילים בתוכנית הנוכחית. במאגר הישן עדיין קיימים 30 כרטיסי ספר; לפני קידום v22 ל־`main` יש לוודא שה־UI מציג את היקף התוכן הרצוי בלי למחוק את מאגר ההרחבה.
- כשהציור קם לתחייה — 22 מפגשים.
- תיאטרון בובות — 5 הצגות נבחרות.
- עולם קטן, קסם גדול — 9 פעילויות.
- שיר נולד בגן — 22 מפגשים.

## פרסום

Netlify מפרסם את האתר הסטטי מתוך התיקייה `public` לפי `netlify.toml`.

## תהליך Release

1. עבודה על `release/storyos-v22-production`.
2. Smoke Test ו־QA על כל חמש הפעילויות.
3. בדיקת Netlify branch/deploy preview.
4. אישור ידני סופי.
5. Merge ל־`main` ופרסום Production.

## זכויות תוכן

יש להשתמש בכריכות, באיורים, בסריקות ובתוכן ספרים בהתאם להרשאות ולרישיונות המתאימים.
