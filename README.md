# StoryOS – סבא שמעון

מרכז הפעלה דיגיטלי בעברית לשעות סיפור, פעילויות, מצגות ומעקב אישי.

## מה נוסף בגרסה 12

- הורדת כריכת ספר ישירות מכרטיס הספר או מעמוד הפרטים.
- הורדת פוסטר פעילות ישירות מכרטיס הפעילות או מעמוד הפרטים.
- התאמה למסכי מחשב וטלפון.
- הפרדת התמונות מה־HTML לקבצים יעילים יותר לפרסום ברשת.
- קובץ נתוני 30 הספרים נשמר לצד האפליקציה.

## פרסום

הפרויקט מוכן לפרסום סטטי ב־Netlify מתוך התיקייה `public`.

## זכויות תוכן

יש להשתמש בתמונות הכריכות, בפוסטרים ובתוכן הספרים בהתאם להרשאות ולרישיונות המתאימים.
