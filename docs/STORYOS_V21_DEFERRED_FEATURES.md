# StoryOS V21 — Deferred Features Backlog

מסמך זה מיועד לרעיונות שאושרו עקרונית אך **לא מטופלים כעת**, כדי לא להסיט את הפיתוח מהיעד הנוכחי: להעמיד ולבדוק את V21 העובדת.

## 1. משוב גננת אוטומטי לאחר פעילות

**סטטוס:** DEFERRED — לא לפתח כרגע.

### הרעיון
לאחר שהמפעיל מסיים פעילות ומדווח יציאה, המערכת תוכל לתזמן שליחת בקשת משוב לגננת/איש הקשר לאחר פרק זמן מוגדר, לדוגמה כשעתיים–שלוש לאחר סיום הפעילות.

### חוויית המשוב
המשוב צריך להיות קצר מאוד ולדרוש מינימום הקלדה. הכיוון המועדף הוא שאלון מסוג Check / Quick Feedback, לדוגמה:

- האם הפעילות התאימה לילדים? כן / לא / חלקית.
- האם הילדים היו מעורבים? כן מאוד / כן / מעט / לא.
- האם המפעיל הגיע בזמן? כן / לא.
- האם היית מזמינה פעילות נוספת? כן / אולי / לא.
- דירוג כללי קצר, למשל 1–5 או בחירה מילולית.
- שדה הערות חופשי — אופציונלי בלבד.

### זרימה עתידית מוצעת
`Check-out → delay configurable → Feedback Request → one-tap form → save response → link to session + institution + operator + activity`

### הנתונים שנרצה לשמור בעתיד
- session_id
- institution_id
- contact_id
- operator_id
- activity_id
- sent_at
- opened_at
- submitted_at
- structured_answers
- optional_comment
- overall_score
- consent/public-use flag אם נרצה להשתמש בציטוט בעתיד

### שימושים עתידיים אפשריים
- בקרה על איכות הפעילויות.
- מדידת שביעות רצון לפי גן, פעילות ומפעיל.
- זיהוי בעיות חוזרות.
- שיפור תכנים.
- המלצות פנימיות לפעילות הבאה.
- יצירת עדויות/Testimonials לאתר או פורטפוליו, **רק כאשר יש אישור מתאים לשימוש פומבי**.
- Dashboard של שביעות רצון לאורך זמן.

### הערה חשובה
יש להפריד בין **משוב פנימי** לבין **הסכמה לפרסום**. גם אם גננת כתבה תגובה חיובית, אין להניח אוטומטית שניתן לפרסם אותה באתר. אם נרצה להשתמש בציטוט פומבי, כדאי לשמור הסכמה מפורשת ונפרדת.

### החלטת מוצר כרגע
לא לשנות Schema, UI או APIs עבור הפיצ'ר הזה לפני סיום בדיקת V21 הנוכחית.

**אחרי שהמערכת הבסיסית תיבדק ותעבוד, יש לחזור לפיצ'ר הזה ולשאול האם להתחיל לטפל בו.**
